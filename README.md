# 📊 Dashboard Comercial de Ventas | Power BI

Proyecto de **Business Intelligence** desarrollado en **Microsoft Power BI** para analizar el desempeño comercial de una empresa mediante indicadores de ventas, productos, categorías y vendedores.

---

## 📌 Resumen ejecutivo

Este proyecto transforma datos comerciales en un dashboard ejecutivo que permite monitorear el comportamiento de las ventas y facilitar la toma de decisiones mediante visualizaciones interactivas y KPIs.

La solución incluye procesos de limpieza y transformación en **Power Query**, modelado de datos y creación de medidas **DAX** para obtener información accionable desde una única vista.

## 🎯 Problema de negocio

Los registros comerciales contenían información dispersa sobre ventas, productos, clientes y vendedores, lo que dificultaba responder preguntas clave como:

* ¿Cómo evolucionan las ventas en el tiempo?
* ¿Qué productos generan mayores ingresos?
* ¿Qué categorías tienen mejor desempeño?
* ¿Qué vendedores obtienen los mejores resultados?
* ¿Dónde existen oportunidades de mejora comercial?

## ✅ Objetivos del proyecto

* Analizar el comportamiento histórico de las ventas.
* Identificar los productos y categorías más rentables.
* Comparar el desempeño entre vendedores.
* Construir un dashboard interactivo orientado a usuarios de negocio.

## 📂 Dataset

El proyecto utiliza una base de datos comercial proporcionada durante el curso de **Excel Avanzado y Power BI de Colsubsidio**, con información sobre:

* Ventas
* Productos
* Clientes
* Categorías
* Vendedores

Los datos fueron preparados mediante **Power Query** antes de construir el modelo analítico.

## 📈 Dashboard Ejecutivo

El tablero permite analizar la información mediante filtros dinámicos y visualizaciones interactivas.

### KPIs principales

* Ventas Totales
* Cantidad de Ventas
* Ticket Promedio
* Desempeño por Categoría
* Ranking de Productos
* Rendimiento por Vendedor

## 🔍 Proceso analítico

1. Importación de datos desde Excel.
2. Limpieza y estandarización en Power Query.
3. Modelado relacional.
4. Creación de medidas DAX.
5. Diseño de visualizaciones.
6. Construcción del dashboard ejecutivo.

## 💡 Principales hallazgos

* El dashboard facilita identificar los productos con mayor contribución a las ventas.
* Permite comparar el desempeño entre categorías y vendedores.
* Los filtros dinámicos agilizan el análisis por diferentes dimensiones del negocio.
* La visualización mejora la interpretación de los indicadores para usuarios no técnicos.
