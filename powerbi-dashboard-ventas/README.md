# \# 📊 Dashboard de Ventas | Power BI

# 

# Proyecto de análisis de ventas desarrollado en Power BI como parte del curso de \*\*Excel Avanzado y Power BI\*\* de \*\*Colsubsidio\*\*.

# 

# \---

# 

# \# 🎯 Objetivo

# 

# Desarrollar un dashboard interactivo que permitiera analizar el desempeño comercial mediante indicadores clave de ventas, facilitando el seguimiento de resultados y apoyando la toma de decisiones.

# 

# \---

# 

# \# 🗂 Dataset

# 

# El proyecto utiliza un conjunto de datos de ventas suministrado durante el curso de Excel Avanzado y Power BI de Colsubsidio con fines académicos.

# 

# El dataset contiene información sobre:

# 

# \- Clientes

# \- Productos

# \- Categorías

# \- Fechas

# \- Métodos de pago

# \- Ventas

# \- Utilidad

# 

# \---

# 

# \# ❓ Preguntas de negocio

# 

# El dashboard responde preguntas como:

# 

# \- ¿Cuáles son las categorías con mayores ventas?

# \- ¿Qué clientes generan más ingresos?

# \- ¿Cuál es el método de pago más utilizado?

# \- ¿Cómo evolucionan las ventas en el tiempo?

# 

# \---

# 

# \# 📈 KPIs

# 

# \- 💰 Total de ventas

# \- 📦 Cantidad de pedidos

# \- 💵 Utilidad

# \- 🛒 Ticket promedio

# \- 📊 Margen

# 

# \---

# 

# \# 📊 Visualizaciones

# 

# El dashboard incluye:

# 

# \- Tarjetas KPI

# \- Gráfico de ventas por categoría

# \- Ventas por método de pago

# \- Evolución de ventas en el tiempo

# \- Segmentación por cliente

# \- Filtros interactivos

# 

# \---

# 

# \# 💡 Principales Insights

# 

# El dashboard permite:

# 

# \- Identificar las categorías con mejor desempeño.

# \- Detectar los clientes con mayor generación de ingresos.

# \- Analizar la evolución de las ventas en el tiempo.

# \- Evaluar el comportamiento de los métodos de pago.

# \- Facilitar el seguimiento de indicadores comerciales mediante visualizaciones dinámicas.

#
